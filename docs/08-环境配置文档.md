## 二、Windows环境配置

### 2.1 安装JDK 17

1. 下载JDK 17：https://adoptium.net/download/ （选择 Windows x64 MSI Installer）
2. 安装到默认路径（如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.9.9-hotspot\`）
3. 配置环境变量：
   - `JAVA_HOME` = JDK安装路径
   - `PATH` 添加 `%JAVA_HOME%\bin`
4. 验证：`java -version` → 显示 `openjdk version "17.0.x"`

### 2.2 安装Node.js 18+

1. 下载：https://nodejs.org/ （选择 LTS 版本，18.x 或 20.x）
2. 安装到默认路径
3. 验证：`node -v` → 显示 `v18.x.x` 或 `v20.x.x`
4. 验证npm：`npm -v`

### 2.3 安装Git

1. 下载：https://git-scm.com/download/win
2. 安装选项：默认即可，编辑器选VS Code
3. 配置用户信息：
```bash
git config --global user.name "你的姓名"
git config --global user.email "你的邮箱"
```

### 2.4 安装Docker Desktop

1. 下载：https://www.docker.com/products/docker-desktop/
2. 安装后确保WSL2已启用（Windows 10/11）
3. 启动Docker Desktop，确保状态为"Engine running"
4. 验证：`docker --version`

### 2.5 安装Maven

1. 下载：https://maven.apache.org/download.cgi （Binary zip archive）
2. 解压到 `C:\apache-maven-3.9.x`
3. 配置环境变量：
   - `MAVEN_HOME` = Maven解压路径
   - `PATH` 添加 `%MAVEN_HOME%\bin`
4. 验证：`mvn -version`

### 2.6 安装Python 3.10+

1. 下载：https://www.python.org/downloads/ （选择 3.10.x 或 3.11.x）
2. 安装时勾选"Add Python to PATH"
3. 验证：`python --version` → 显示 `Python 3.10.x`
4. 安装AI推荐服务依赖：
```bash
pip install flask scikit-learn scipy pandas numpy
```

## 三、macOS环境配置

### 3.1 使用Homebrew安装


## 四、Docker环境搭建（推荐）

### 4.1 docker-compose.yml

在项目根目录创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: campus-mysql
    environment:
      MYSQL_ROOT_PASSWORD: root123456
      MYSQL_DATABASE: campus_trade
      MYSQL_USER: campus
      MYSQL_PASSWORD: campus123
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
      - ./deploy/init.sql:/docker-entrypoint-initdb.d/init.sql
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      timeout: 20s
      retries: 10

  redis:
    image: redis:7-alpine
    container_name: campus-redis
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    command: redis-server --appendonly yes
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s

  # AI推荐服务（Python Flask）
  recommend:
    build: ./apps/recommend
    container_name: campus-recommend
    ports:
      - "5000:5000"
    environment:
      - MYSQL_HOST=mysql
      - MYSQL_DB=campus_trade
    depends_on:
      mysql:
        condition: service_healthy
    restart: unless-stopped

  # Elasticsearch（可选，论坛全文搜索）
  elasticsearch:
    image: elasticsearch:8.11.0
    container_name: campus-es
    environment:
      - discovery.type=single-node
      - xpack.security.enabled=false
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
    ports:
      - "9200:9200"
    volumes:
      - es-data:/usr/share/elasticsearch/data
    profiles:
      - full  # 仅在 full profile 下启动

volumes:
  mysql-data:
  redis-data:
  es-data:
```

### 4.2 启动环境

```bash
# 项目根目录
docker compose up -d

# 查看状态
docker compose ps

# 停止环境
docker compose stop

# 完全删除（含数据）
docker compose down -v
```

## 五、项目启动

### 5.1 克隆仓库

```bash
git clone <仓库地址>
cd campus-secondhand-platform
```

### 5.2 启动后端

```bash
# 进入后端目录
cd apps/backend

# 方式一：使用Maven命令行
mvn spring-boot:run

# 方式二：在IDEA中
# 1. File → Open → 选择 apps/backend 目录
# 2. 等待Maven依赖下载完成
# 3. 运行 CampusApplication.java 主类

# 验证：访问 http://localhost:8080/api/v1
```

```bash

cd apps/frontend

# 安装依赖
npm install

# 访问 http://localhost:5173
```

后端启动后，访问：`http://localhost:8080/doc.html`

## 六、配置文件说明

### 6.1 后端 application.yml

```yaml
# apps/backend/src/main/resources/application.yml
server:
  port: 8080

spring:
  profiles:
    active: dev  # 默认使用dev配置
  
  datasource:
    url: jdbc:mysql://localhost:3306/campus_trade?useUnicode=true&characterEncoding=utf8mb4&serverTimezone=Asia/Shanghai
    username: campus
    password: campus123
    driver-class-name: com.mysql.cj.jdbc.Driver
  
  data:
    redis:
      host: localhost
      port: 6379
  
  servlet:
    multipart:
      max-file-size: 5MB
      max-request-size: 50MB

# MyBatis-Plus配置
mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml
  global-config:
    db-config:
      logic-delete-field: isDeleted
      logic-delete-value: 1
      logic-not-delete-value: 0
  configuration:
    map-underscore-to-camel-case: true
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl  # 开发环境打印SQL

# JWT配置
jwt:
  secret: your-256-bit-secret-key-here-must-be-long-enough
  access-token-expiration: 86400000   # 24小时（毫秒）
  refresh-token-expiration: 604800000  # 7天

# 校园网IP段配置（注册时检测，待学校网络中心提供）
campus:
  ip-ranges:
    - 10.0.0.0/8        # 校园网A类私有地址
    - 172.16.0.0/12     # 校园网B类私有地址
    - 192.168.0.0/16    # 校园网C类私有地址
  # 示例配置，实际IP段以学校网络中心提供为准
  ip-check-enabled: true  # 是否开启IP检测（开发环境可设为false）

# 文件上传
upload:
  path: ./uploads  # 本地存储路径
  max-size: 5242880  # 5MB

# AI推荐服务配置
recommend:
  service-url: http://localhost:5000  # Python推荐服务地址
  cold-start-threshold: 10             # 冷启动阈值（行为<10条时使用热门兜底）
  update-interval: 7200000             # 推荐结果更新间隔（2小时）

# 论坛配置
forum:
  daily-post-limit: 10                 # 每日发帖上限
  sensitive-words-enabled: true        # 敏感词过滤开关

# Knife4j配置
springdoc:
  swagger-ui:
    path: /swagger-ui.html
knife4j:
  enable: true
  setting:
    language: zh_cn
```

## 七、常见问题

### 7.1 MySQL连接失败

```bash
# 检查Docker容器是否在运行
docker compose ps

# 检查端口是否被占用
netstat -ano | findstr 3306   # Windows
lsof -i :3306                # macOS/Linux

# 如果本地已有MySQL占用了3306端口，修改docker-compose端口映射
# 如改为 "3307:3306"
```

### 7.2 Maven依赖下载慢

在 `~/.m2/settings.xml` 中配置阿里云镜像：

```xml
<mirrors>
  <mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <name>Aliyun Maven</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### 7.3 npm安装依赖慢

```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 或使用pnpm替代npm
npm install -g pnpm
pnpm install
```

### 7.4 端口被占用

```bash
# Windows：查找占用端口的进程
netstat -ano | findstr :8080
taskkill /PID <PID> /F

# macOS/Linux：
lsof -i :8080
kill -9 <PID>
```
