## 一、部署架构

系统采用前后端分离架构，配合 AI 推荐微服务。建议生产环境使用 Docker 容器化部署。

```
[ 用户浏览器 ] 
      │
      ▼
[ Nginx (端口 80/443) ] ───静态资源 (Vue3 Build Files)
      │
      ├─ 反向代理 (/api) ───▶ [ Spring Boot Java Backend (端口 8080) ]
      │                                     │
      │                                     ├─▶ [ MySQL 8.0 ]
      │                                     ├─▶ [ Redis 7.0 ]
      │                                     └─▶ [ RabbitMQ ]
      │
      └─ 反向代理 (/ai) ────▶ [ Python Flask AI Service (端口 5000) ]
```

## 二、环境要求

### 2.1 硬件要求
- **CPU**: 至少 2 核 (建议 4 核)
- **内存**: 至少 4GB (建议 8GB)
- **磁盘**: 40GB+

### 2.2 软件依赖
- **操作系统**: CentOS 7.9+ 或 Ubuntu 20.04+ (建议使用 Docker)
- **Docker**: 20.10.x+
- **Docker Compose**: 2.x+
- **JDK**: 17 (后端编译)
- **Node.js**: 18.x (前端构建)
- **Python**: 3.10+ (AI 服务)

## 三、部署步骤 (Docker-Compose 方式)

### 3.1 准备工作

1. 克隆代码仓库：
   ```bash
   git clone https://github.com/your-repo/campus-secondhand-platform.git
   cd campus-secondhand-platform
   ```

2. 准备环境变量文件 `.env` (位于根目录)：
   ```env
   MYSQL_ROOT_PASSWORD=your_password
   MYSQL_DATABASE=campus_trade
   REDIS_PASSWORD=your_redis_password
   JWT_SECRET=your_jwt_secret_key
   ```

### 3.2 数据库初始化

系统启动时会自动执行 `deploy/mysql/init.sql`。若需手动执行：
```bash
docker exec -i mysql_container mysql -uroot -p$MYSQL_ROOT_PASSWORD campus_trade < docs/04-数据库设计文档.md 中的 SQL 脚本
```

### 3.3 构建并启动

```bash
# 赋予执行权限
chmod +x build.sh

# 执行构建并启动
docker-compose up -d --build
```

## 四、各组件配置详解

### 4.1 Nginx 配置示例 (`deploy/nginx/conf.d/default.conf`)

```nginx
server {
    listen 80;
    server_name campus.trade.com;

    # 前端静态资源
    location / {
        root /usr/share/nginx/html;
        index index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /api/v1/ {
        proxy_pass http://backend:8080/api/v1/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # AI 推荐服务反向代理
    location /ai/ {
        proxy_pass http://recommend:5000/;
        proxy_set_header Host $host;
    }

    # WebSocket 支持 (用于即时通知)
    location /ws/ {
        proxy_pass http://backend:8080/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
    }
}
```

### 4.2 后端 Spring Boot 配置 (`application-prod.yml`)

```yaml
spring:
  datasource:
    url: jdbc:mysql://mysql:3306/campus_trade?useUnicode=true&characterEncoding=utf-8&useSSL=false
    username: root
    password: ${MYSQL_ROOT_PASSWORD}
  redis:
    host: redis
    port: 6379
    password: ${REDIS_PASSWORD}
  rabbitmq:
    host: rabbitmq
```

## 五、环境验证

1. **服务检查**: `docker-compose ps` 确认所有容器状态为 `Up`。
2. **API 连通性**: 访问 `http://<server-ip>/api/v1/auth/me` 应返回 401（未登录）。
3. **前端访问**: 浏览器访问 `http://<server-ip>/` 应能看到首页。
4. **日志检查**: 
   - 后端日志: `docker logs -f backend`
   - AI 服务日志: `docker logs -f recommend`

## 六、日常运维与备份

### 6.1 数据库备份
建议每日凌晨 2 点执行：
```bash
docker exec mysql_container mysqldump -u root -p$MYSQL_ROOT_PASSWORD campus_trade > /backup/db/trade_$(date +%F).sql
```

### 6.2 日志滚动
Docker 容器日志默认不限制大小。建议配置 `/etc/docker/daemon.json`:
```json
{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m",
    "max-file": "3"
  }
}
```

### 6.3 常见问题排查 (FAQ)

- **Q: 注册时一直提示"非校园网IP"?**
  - A: 检查 `campus_ip_range` 表中是否录入了正确的学校 IP 段；检查 Nginx 是否透传了真实 IP (`X-Real-IP`)。
- **Q: 图片上传失败?**
  - A: 检查部署服务器的 `/uploads` 目录读写权限；检查 Docker 挂载路径是否正确。
- **Q: 推荐位显示空白?**
  - A: 确认 AI 推荐服务容器是否正常运行；初期需积累至少 10 条用户行为数据才会生成推荐结果。
