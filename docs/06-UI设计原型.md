# 校园智能生活服务平台 - UI设计原型

> **文档版本**: v1.0  
> **编制人**: 前端负责人（C）  
> **审批人**: 全体团队成员  
> **设计工具**: Figma 或 手绘原型  
> **UI组件库**: Element Plus  
> **设计原则**: 简洁、高效、校园风格  
> **最后更新**: 2026-06-02

## 一、设计系统

### 1.1 色彩方案

| 用途 | 色值 | 说明 |
|------|------|------|
| **主色调** | `#2B5CED` | 校园蓝，代表信任和专业 |
| **主色浅** | `#E8EEFD` | 浅蓝背景、选中态 |
| **成功色** | `#52C41A` | 交易完成、操作成功 |
| **警告色** | `#FAAD14` | 待处理状态 |
| **危险色** | `#FF4D4F` | 取消、删除操作 |
| **文字主色** | `#1F2937` | 标题、正文 |
| **文字辅色** | `#6B7280` | 次要信息、时间 |
| **边框色** | `#E5E7EB` | 卡片边框、分割线 |
| **背景色** | `#F3F4F6` | 页面背景 |
| **白色** | `#FFFFFF` | 卡片、容器背景 |

### 1.2 字体规范

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 24px | 600 | 页面主标题 |
| H2 | 20px | 600 | 区块标题 |
| H3 | 16px | 500 | 卡片标题 |
| Body | 14px | 400 | 正文内容 |
| Caption | 12px | 400 | 辅助信息、时间戳 |
| Price | 20px | 700 | 价格展示（特殊强调） |

### 1.3 间距规范

| 级别 | 值 | 用途 |
|------|-----|------|
| xs | 4px | 紧密元素间距 |
| sm | 8px | 相关元素间距 |
| md | 16px | 组件内间距 |
| lg | 24px | 区块间距 |
| xl | 32px | 页面边距、大区块 |

### 1.4 圆角与阴影

| 元素 | 圆角 | 阴影 |
|------|------|------|
| 按钮 | 6px | 无 |
| 输入框 | 6px | 无 |
| 卡片 | 8px | `0 2px 8px rgba(0,0,0,0.08)` |
| 弹窗 | 12px | `0 4px 16px rgba(0,0,0,0.12)` |
| 头像 | 50% (圆形) | 无 |

**顶部导航栏**（固定顶部，高度56px）：
- 左侧：Logo + 平台名称"校园生活"
- 中间：导航标签（首页 | 二手 | 租赁 | 换物 | 清仓 | 论坛 | 兼职 | 拼卡）+ 搜索框
- 右侧：发布按钮（下拉菜单：发布商品/发布换物/发布租赁/发布兼职/发帖）+ 用户头像下拉菜单

**顶部导航标签**：首页 | 二手 | 租赁 | 换物 | 清仓 | 论坛 | 兼职 | 拼卡  
**AI推荐区域**："猜你喜欢"基于用户行为个性化推荐，每张卡片标注推荐理由（如"根据你浏览过的电脑配件推荐"）  
**热门商品区域**：新用户冷启动策略，展示全站热门商品  
**清仓活动横幅**：即将到期的活动突出展示

**响应式适配**（移动端）：
- 导航标签收起为横向滑动
- 商品网格变为2列
- 推荐区域变为横向滑动卡片

## 三、交互规范

### 3.1 加载状态

| 场景 | 交互方式 |
|------|----------|
| 页面初次加载 | 骨架屏（Skeleton Screen） |
| 下拉刷新 | 顶部加载条 + 动画 |
| 按钮提交 | 按钮显示loading + 禁用点击 |
| 图片加载 | 渐进加载：模糊占位图 → 清晰图 |
| 列表加载更多 | 底部无限滚动或"加载更多"按钮 |

### 3.2 空状态

| 场景 | 空状态提示 |
|------|-----------|
| 搜索无结果 | 🔍 "没有找到相关商品，试试其他关键词吧" |
| 我的发布为空 | 📦 "还没有发布商品，去发布第一个吧" [发布按钮] |
| 我的收藏为空 | ❤️ "还没有收藏商品，去首页逛逛吧" [去逛逛] |
| 订单为空 | 📋 "还没有交易记录" |

### 3.3 错误与确认

| 场景 | 交互方式 |
|------|----------|
| 表单校验失败 | 字段下方红色提示 + 输入框红框 |
| 网络错误 | Toast提示"网络连接失败，请重试" + 重试按钮 |
| 删除操作 | 弹出确认对话框"确定删除？删除后不可恢复" |
| 取消订单 | 弹出确认对话框，需填写取消原因 |
| Token过期 | 自动弹出登录弹窗或跳转登录页 |

### 3.4 页面过渡

| 场景 | 动效 |
|------|------|
| 页面切换 | Fade in (0.2s) |
| 弹窗打开 | 缩放 + Fade in (0.2s) |
| 列表项删除 | 滑动消失 (0.3s) |
| 图片轮播 | 滑动过渡 (0.3s) |

## 四、移动端适配（响应式）

### 4.1 断点定义

| 断点 | 设备 | 布局变化 |
|------|------|----------|
| < 768px | 手机 | 2列商品网格，底部导航，分类折叠 |
| 768px - 1024px | 平板 | 3列商品网格，侧边分类导航 |
| > 1024px | 桌面 | 4列商品网格，侧边分类导航 |

### 4.2 移动端特殊适配

- **底部固定按钮**：商品详情页的"立即购买"、订单页的"确认交易"固定底部
- **手势操作**：图片轮播支持左右滑动
- **触摸友好**：可点击区域最小44×44pt
- **安全区域**：适配iPhone刘海屏/底部指示条安全区域
